# game — 공개 참고·안내 저장소

이 저장소는 과거 **AFTERLIGHT**의 설명·설정·실행기 일부를 보존하는 공개 참고 자료입니다. 현재 **첫길(FIRSTPATH)**의 소스와 내부 작업 기록은 별도 비공개 저장소에서 선별 보존합니다.

## 공개된 범위
현재 트리에는 README, AGENTS, package.json, .gitignore, serve.py 및 실행용 CMD·SH 파일이 있습니다.
게임 본체(dist), 프로젝트 스크립트·테스트·작업그래프, Unity 프로젝트, 에셋과 검증 결과 전체는 포함하지 않습니다.

따라서 이 저장소를 clone하거나 ZIP으로 받아도 **전체 게임 실행·작업 대시보드 실행·자동화 작업 재개를 재현할 수 없습니다.**
package.json과 런처는 과거 자료이며, 참조 파일을 설치해 주는 패키지가 아닙니다.

## 첫길과 AFTERLIGHT의 구분
두 프로젝트의 원본·이력·작업 상태를 합치지 않습니다. 공개 자료가 적다는 사실은 사용자 로컬 원본의 부재나 손상을 뜻하지 않습니다.
비공개 보존 사본도 범위·제외 목록·정확한 해시·복원 검증을 함께 읽어야 하며, 전체 에셋/머신 백업이나 게임 출시·품질 인수와 다릅니다.
