# AFTERLIGHT · 잔광 — 잉크 고딕 그래픽 적용

**현재 기본 실행:** `START-WINDOWS.cmd` 또는 `npm start` → [로컬 게임](http://127.0.0.1:8767/)에서 잉크 고딕 버전을 엽니다. [온라인 게임](https://afterlight-survivors.s99078634.chatgpt.site/)도 같은 그래픽 표본을 기본으로 사용합니다. 검토된 Warden·묘역 적·보스·환경 아트가 적용됐으며 전체 아트와 휴대폰 실기기 검증은 진행 중입니다. [적용 결과](docs/GRAPHICS-DEFAULT-RESULTS.md).

기존 로컬 v0.3은 [이전 버전](http://127.0.0.1:8767/v03.html)으로 보존했습니다. 아래 v0.3 설명과 검증 명령은 보존 버전에 해당합니다.

**프로젝트 조직·작업 대시보드:** `START-DASHBOARD.cmd` 또는 `npm run dashboard` → [로컬 프로젝트 관측소](http://127.0.0.1:8792/). 조직도, 부서별 담당·작업, 프랙탈OS 코치의 병목·다음 행동, 검증 근거를 확인합니다. [사용법과 상태 해석](docs/ORGANIZATION-DASHBOARD.md).

> 보존된 v0.3 진입점은 `dist/v3/app.mjs`입니다. [실제 구현 기록](docs/IMPLEMENTATION-v0.3.md), [검증 결과](docs/EVAL-RESULTS-v0.3.md), [배포 상태](loop/release-v0.3.json)를 분리해 기록합니다.

**다음 버전 기획:** 사용자 피드백 12개를 반영한 [v0.4 군세와 변형 빌드 Spec](docs/AFTERLIGHT-SPEC-v0.4.md)을 추가했습니다. [16분기·직업·위상·옵션](docs/BUILD-CATALOG-v0.4.md), [현재 코드 감사와 비교작 근거](docs/RESEARCH-v0.4.md), [상세 Loop](docs/ARCHITECTURE-LOOP-v0.4.md), [Eval](docs/EVAL-PLAN-v0.4.md), [ISW 검토](docs/SPEC-REVIEW-v0.4.md)를 포함합니다. 이 문단은 v0.3 당시의 계획 기록입니다. 현재 기본 실행은 상단의 v0.4.2 기반 잉크 고딕 그래픽 표본입니다.

보조젬으로 스킬의 동작을 바꾸고, 시간 보스를 공략해 장비를 회수하는 로컬 브라우저 생존 액션 RPG입니다. 360도 이동과 사선 시점의 성역·캐릭터·몬스터 스프라이트를 사용합니다.

## 실행

1. 전체 압축을 풉니다. `게임/뱀파이어 서바이벌 장르` 폴더로 들어갑니다.
2. Windows: `START-WINDOWS.cmd`를 실행합니다. Python 3.9 이상 또는 Node.js 18 이상 중 하나가 필요합니다. 별도 npm 패키지 설치는 없습니다.
3. 브라우저에서 캐릭터·모드·난이도·출발 스킬·보조젬을 고르고 원정을 시작합니다.

자동으로 열리지 않으면 [로컬 게임](http://127.0.0.1:8767)을 엽니다. 실행 창은 플레이하는 동안 열어둡니다. macOS/Linux는 `sh START-MAC-LINUX.sh`. 직접 실행은 `python3 serve.py` 또는 `node scripts/serve.mjs`입니다. 두 서버는 `127.0.0.1:8767`만 사용합니다.

`index.html` 더블클릭은 ES 모듈 제약 때문에 지원하지 않습니다. 실행기가 이미 켜져 있다면 기존 창을 사용하세요.

## 조작과 원정

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 · 공격은 자동 |
| Space | 0.18초 무적 대시 |
| Q | 가까운 보스 우선 지휘, 없으면 가까운 적을 2초 지정 |
| E | 가까운 환경 장치 작동 |
| R | 씨앗 회수 위상 사용 |
| Esc | 일시정지 |
| 화면 드래그 | 터치 이동 · 오른쪽 대시/지휘 버튼 |
| 설정의 마우스 조준 | 공격 방향을 포인터로 지정 |

- 20분: 5·10·15분 중간 보스, 18분 최종 보스. 20분 안에 최종 보스를 처치합니다.
- 30분: 5·10·15·20·25분 중간 보스, 28분 최종 보스. 30분 안에 처치합니다.
- 무한: 5분마다 보스가 순환합니다. 캠프에서 전리품과 함께 귀환할 수 있습니다. 보스마다 2분 제한입니다.
- 이야기·표준·숙련·고행 4난이도. 진행 중에는 낮출 수 있습니다. 전투 속도와 예고 여유 설정도 제공합니다.
- 선택·캠프에서는 시간이 멈춥니다. 최대 4스킬, 스킬마다 3보조젬, 6종 패시브, 1키스톤을 구성합니다.
- 새 장비 가방은 12칸. 보스 상자를 고르면 새 장비를 모두 송환합니다. 최종 상자 선택은 송환과 승리 정산으로 이어집니다. 실패하면 미송환 장비만 잃고 기존 장비·획득 재료는 유지합니다.
- 송환 장비는 비교·착용·잠금·분해·재연마·목표 제작이 가능합니다. 보스 훈련에는 8개 주력 조합이 있습니다.

## v0.3에서 달라진 것

- **6지역·18배치**: 지역 도감에서 체험할 수 있습니다. 무한 원정은 여섯 지역을 섞어 순환합니다.
- **환경 전투**: 기름·수문·용암·포자·낙석·수정은 적과 자신 모두에게 영향을 줍니다. 노란 예고와 고체 엄폐를 활용하세요.
- **사운드와 이미지**: 8종 타격 질감, 배경음, 위험음 우선 재생. 스킬·보조·장비에 44개 원본 아이콘을 연결했습니다.
- **피해 분석**: 피해·시전 간격·기준/조건부/최근 10초 DPS. 보스 훈련에서 30초 허수아비도 선택할 수 있습니다.
- **장비 가공**: 위상 도감·각인, 확정 마법 부여, 수치 연마. 일반 옵션 종류는 기존 24개를 유지합니다.
- **심도와 준비 출발**: 표준 20분 성장 원정 완료로 D1과 Lv.14 준비 출발을 해금합니다. D1–12와 선택 위험 규칙, D3 정점 보스를 제공합니다.

## 저장

IndexedDB에 장비·재료·최근 200판·진행 중 한 판을 저장합니다. 전투 시간 60초마다, 정지·주요 보상 거래 때 체크포인트를 남깁니다. 저장은 현재 주소와 브라우저에 속합니다.

강제 종료하면 마지막 체크포인트 이후 진행은 잃을 수 있습니다. 정지/캠프의 **저장하고 성역으로**를 사용하세요. 설정의 **파일 백업**은 진행 중인 판까지 JSON으로 내보냅니다. 가져오기는 진행 중인 판이 없는 계정에서 지원하며 교체 전 확인 화면을 표시합니다. 진행 중인 v0.2 원정은 기존 화면에서 마무리하고 돌아오면 계정을 v0.3으로 변환합니다. 이전 장비 수치·재료 총량·사용 횟수를 보존합니다. 읽을 수 없는 진행은 원본 백업 후 해당 체크포인트만 삭제할 수 있습니다.

저장 불가·다른 탭 충돌·저장 실패를 화면에 알립니다. 계정과 진행을 함께 복제하고 거래 성공 뒤에만 적용해 저장 실패로 전리품이 먼저 사라지는 것을 막습니다.

[구현 현황·실제 아키텍처](docs/IMPLEMENTATION-v0.3.md), [평가 결과·한계](docs/EVAL-RESULTS-v0.3.md), [현재 실행 규약](loop/project.json)을 확인하세요.

```sh

```

평가는 봇 진행·보스 주력 조합·120분 상태 누적·밀집 적 600·고유 보정을 측정합니다. `--quick`은 120분 검사를 생략합니다. Node 수치는 실제 브라우저 FPS나 사람의 재미 증거가 아닙니다.

현재 여섯 지역의 플레이 가능한 프로토타입입니다. 기본 젬은 개방했고 위상과 심도는 원정 기록으로 해금합니다. 본격적인 프레임 애니메이션·상용 PC 실행 파일은 후속 범위입니다. 기기별 조작·저장 장애·장시간 피로와 완성 빌드 밸런스는 사람 플레이 검증이 남아 있습니다.
